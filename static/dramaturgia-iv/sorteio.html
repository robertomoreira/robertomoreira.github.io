Sorteio de grupos

Dramaturgia Audiovisual IV

A lista fica guardada só neste navegador. Nada é enviado nem publicado.

O nome da tarefa define o sorteio: a mesma tarefa devolve sempre os mesmos grupos.

Grupos do tamanho pedido; se sobrar um aluno sozinho, ele é distribuído nos primeiros grupos. "Outro sorteio" gera um arranjo alternativo para a mesma tarefa (variante 2, 3…). A última tarefa é montada pelos próprios alunos.
